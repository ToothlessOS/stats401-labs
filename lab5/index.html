Node-link Encoding

  1. District - Node color.
  2. Daily passengers - Node size. This is an intuitive representation, as a larger station means more passengers.
  3. Station type - Node texture. Solid for terminals (i.e. dead-end), hollowed for locals (following the convention of Shanghai Metro) and cross for transfers (follwing the conventionof Shenzhen Metro)
  4. Min Travel Time - Link width. A wider links gives the intuition of "getting there more easily", corresponding to shorter traveling time.
  5. Route Type - Link color. I choose a different color scheme from the nodes, so that the users won't get lost.

Node-link Interaction

  1. The nodes can be dragged, allow users to see the layout of the network more easily.
  2. When hovering above any node or link, a tooltip gives specific information of the station or route. The neightbouring routes and stations also get highlighted. As the current visualization is quite complex, this help the user to focus on individual stations / routes.

Adj. MAT Encoding

  1. Row / Column - Stations.
  2. Filled cells - Direct connection.
  3. Cell color - travel time

As this is a very large adjancency matrix, trying to pack too many variables into the visualization will make it hard to read. Therefore, I only preserved direction connections and travel times, which are the most important variables for travellers. The district / type of the two connecting stations and the route type are presented via the tooltip.

Q&A

  1. Which stations appear central in the network? - Station 38; From the Node-Link graph, we can see it is a large station (node size) with short travel times (link width) to three other large stations in different districts (node color) . This makes it important in the network.
  2. Which districts are strongly connected to one another? - It's hard to name a specific pair of districts. From the node-link graph, we can see that many nodes with different colors (from different district) are interconnected. There are strong connections between all of the districts.
  3. Where are transfer or terminal stations located in the topology? - All transfer stations are located in the connected part of the node-link graph.
  4. Which stations have high passenger volume? - Station 48, 49, 50; Indicated by the node size in the node-link graph.
  5. Where are the longest direct travel-time connections? - Station 7 and Station 31; This is given by the darkest orange square on the adjancency matrix.
  6. Are particular route types concentrated in particular parts of the network? - From the node-link graph, I cannot tell this from the visualization - the links of different colors (route types) are mixed together and I cannot find a concentrated pattern.
